# google-cloud-console-color

Google Cloud Console のヘッダー色を、表示中のプロジェクト ID ごとに変える Chrome 拡張。
複数プロジェクトを行き来するときに、本番環境で操作していることに気づけるようにするためのもの。

## インストール

1. このリポジトリを clone する
2. `chrome://extensions` を開き、右上の **デベロッパーモード** を ON
3. **パッケージ化されていない拡張機能を読み込む** から clone したディレクトリを選択

## 使い方

ツールバーの拡張機能アイコンから設定を開き、ルールを追加する。

| 項目 | 内容 |
| --- | --- |
| パターン | プロジェクト ID と比較する文字列 |
| 一致方法 | 完全一致 / 前方一致 / 後方一致 |
| 色 | ヘッダーに適用する色 |

ルールは**上から順に照合され、最初に一致したもの**が使われる。
どのルールにも一致しないプロジェクトや、プロジェクトが特定できないページでは色を付けない。

`prod` で終わるプロジェクトを赤にする、といった運用を想定している。

設定を保存すると、開いている Console タブにリロードなしで反映される。
